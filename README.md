# CareBind 프로젝트

**CareBind**는 고령층 장애인과 자원봉사자를 연결하는 **AI 기반 실시간 매칭 플랫폼**입니다.  
기존 1365 자원봉사 포털의 한계를 보완하여, 사용자 접근성과 긴급 대응력, 자원봉사자 전문성을 높인 서비스입니다.

---

## 🚀 주요 기능

### 1. 🤖 AI 기반 신속 매칭
- 봉사자의 선호도, 거리, 평점, 봉사 이력 등을 종합적으로 분석
- 사회적 약자의 요청과 상황을 고려해 적합한 자원봉사자를 자동 매칭

### 2. 🎯 장애 종류 및 정도 기반 맞춤형 서비스
- 가입 시 설문을 통해 장애 유형 및 정도를 입력받고,
- 요청 서비스와 사용자 특성을 기반으로 개인화된 매칭 수행

### 3. ✍ 다양한 요청 방식 지원
- **손글씨 촬영**, **음성 녹음**, **텍스트 입력**을 통한 요청 기능 제공
- AI가 자동으로 텍스트를 추출하고 요청을 분류함

### 4. 🚨 긴급상황 대응 시스템
- 요청 위험도가 ‘레벨 5’를 초과할 경우,
- **119/112 등 국가 긴급 시스템과 자동 연동**되어 즉시 대응 가능

### 5. 🏅 자원봉사자 혜택
- 공식 봉사 인증서 발급
- 사회복지, 간호 등 관련 전공자의 **현장실습 또는 인턴십 인정**
- 활동 조건 충족 시 **우수봉사자 표창 수여**

---

## 💡 왜 CareBind인가?

| 기존 1365 포털 | CareBind |
|----------------|----------|
| 정기적·예약형 중심, 긴급 대응 미흡 | 실시간 긴급 대응 지원 |
| 수동 입력, 낮은 접근성 | AI 자동 분류 및 접근성 강화 |
| 사용자 유형 구분 없음 | 고령층 장애인 맞춤 설계 |
| 봉사자 혜택 제한적 | 인증서, 실습 인정 등 다양한 보상 |
| 봉사자가 직접 신청 | AI 기반 매칭 추천 방식 |

## 🙌 기대 효과

- 고령층 장애인의 **앱 접근성 향상**
- 자원봉사자의 **활동 편의성과 동기부여 증대**
- 긴급 상황에 대한 **즉각적 대응 체계 구축**
- **사회적 약자 대상 봉사 매칭 성공률 향상**
